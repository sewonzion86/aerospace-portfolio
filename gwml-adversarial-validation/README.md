# Independent Reproduction — Adversarial Validation of GW-Like Signal Detectors

## What this is

A from-scratch, independent re-implementation of a published methodology for stress-testing gravitational-wave-like signal classifiers. No code, numbers, or figures were copied from the source study — the full pipeline (toy-chirp waveform generator, colored-noise/ASD model, SNR calibration and whitening, three classifier architectures, seven-condition adversarial stress suite, matched-spectrum hard-negative experiment) was rebuilt independently in Python (NumPy/SciPy/scikit-learn) and executed fresh.

## What this closes beyond the original study

The original study left several limitations open. This reproduction closes each one directly:

- **Ceiling effect on the baseline benchmark** — closed with a systematic 14-point SNR sweep tracing the full chance-to-ceiling detectability curve.
- **Single-architecture result** — closed with a robustness check across three MLP sizes (64 / 128-64 / 256-128-64), all showing the same qualitative behavior.
- **Coarse matched-filter template grid** — closed by densifying from 5 to 25 templates, which confirmed the original study's own suspected cause of its flagged anomaly.
- **No genuinely disjoint waveform-family test** — closed by building a structurally distinct second waveform family and testing zero-shot transfer. This revealed a sharper finding than the original: magnitude-based classifiers transfer near-perfectly across families, while the temporal network doesn't generalize at all (collapses to ~chance).
- **Small seed count** — moved from 5 to 10 seeds throughout.

One limitation — reliance on synthetic data rather than real detector strain — is stated plainly as irreducible within a from-scratch environment, rather than hidden.
