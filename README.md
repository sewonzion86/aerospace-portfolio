## How this repo is organized

Each project folder is currently a self-contained report (PDF or DOCX) with its own README summarizing scope, method, and key results. Supporting calculations are included alongside the final report where applicable. Code referenced in the reports (e.g. the GWML Python pipeline) is embedded and printed in-line in that report rather than split into separate script files — the README for that project notes this explicitly.
